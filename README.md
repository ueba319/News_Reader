# NewsReader

Jetpack Composeを学びながら開発する、個人向けのAndroidニュースリーダーです。

現在は要件定義・仕様策定を進めています。

## ドキュメント

プロジェクトに関する要件、仕様、設計およびテスト資料は、`docs`ディレクトリで管理します。

推奨する閲覧順序に沿って、以下から各資料を確認できます。

1. [要件定義書](./docs/01-requirements/requirements.md)
2. ユースケース（今後追加）
3. アプリ仕様書（今後追加）
4. 画面仕様（今後追加）
5. 技術設計書（今後追加）
6. テスト資料（今後追加）

## ステータス

- [x] プロジェクト作成
- [ ] 要件定義
- [ ] 仕様策定
- [ ] 技術設計
- [ ] 実装
- [ ] テスト

## ドキュメントの管理方針

- 仕様や設計を変更した場合は、実装と同じPull Requestで関連文書も更新する。
- 要件、仕様、設計を区別し、同じ説明を複数の文書へ重複させない。
- 未決定事項は推測で確定せず、`TODO`または「検討中」と明記する。
- 図は可能な限りMermaidで記述し、Git上で変更差分を確認できるようにする。
