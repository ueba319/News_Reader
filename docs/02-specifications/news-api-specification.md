# ニュース取得機能仕様書

## 1. 目的

GNews APIから国内・海外の経済ニュースを取得し、利用者が朝に主要記事を確認できるようにする。

## 2. 取得仕様

| 項目 | 国内 | 海外 |
|---|---|---|
| エンドポイント | GNews Top Headlines | GNews Top Headlines |
| カテゴリ | business | business |
| 言語 | 日本語（ja） | 英語（en） |
| 国 | 日本（jp） | 指定なし |
| API取得上限 | 10件 | 10件 |
| 画面表示上限 | 5件 | 5件 |
| 対象期間 | 取得時点から過去24時間 | 取得時点から過去24時間 |

画像は取得結果として使用せず、画面にも表示しない。

## 3. 記事選定

国内記事は、タイトルまたは説明に経済情勢に関する語句を含む記事を優先する。記事を完全には除外せず、優先記事が不足した場合はAPIの返却順に従って補完する。

主な優先語句は、政府、日銀、経済、景気、物価、金利、金融、為替、賃金、雇用、GDP、貿易、予算、税、市場、産業および投資とする。

国内・海外ともに次の規則を適用する。

1. 同じIDまたはURLの記事を重複表示しない。
2. 異なる配信元の記事を優先する。
3. 異なる配信元だけで5件に満たない場合は、同じ配信元の記事を含めて補完する。
4. APIから取得できた記事が5件未満の場合は、取得できた件数だけ表示する。

## 4. 画面状態

| 状態 | 表示 |
|---|---|
| Loading | 読み込みインジケーター |
| Success | 国内または海外の記事一覧 |
| Empty | 記事がないことを示すメッセージ |
| Error | 取得失敗メッセージと再試行ボタン |

国内・海外はタブで切り替える。記事を選択すると、端末のブラウザで配信元URLを開く。

## 5. 更新

現段階ではアプリ起動時に取得する。取得失敗時は再試行できる。

同一日における再取得の抑制、記事のローカル保存および朝の定期更新は、後続のローカル保存・定期更新PRで実装する。

## 6. 制約

- GNews無料プランのリクエスト間隔を守るため、国内と海外の通信間に1.1秒の待機を設ける。
- APIキーは `local.properties` からビルド時に読み込み、Gitへ登録しない。
- Androidアプリへ埋め込まれたAPIキーを完全には秘匿できないため、一般公開時はバックエンド経由への変更を検討する。
